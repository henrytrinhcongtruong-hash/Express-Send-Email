# Bulk Email Sender (Ứng Dụng Gửi Mail Hàng Loạt)

Ứng dụng web gửi email hàng loạt từ danh sách Excel với thông tin gửi tùy chỉnh.

## Status: 🚧 Planning

Dự án vừa được khởi tạo workspace thành công bằng quy trình `/init`.

## Chức Năng Cơ Bản
1. Nhập email của người gửi
2. Nhập tiêu đề email
3. Nhập nội dung email
4. Import file Excel chứa danh sách email khách hàng
