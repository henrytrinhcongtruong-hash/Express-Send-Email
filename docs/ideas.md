# 💡 Ý Tưởng Dự Án: Bulk Email Sender

## Mô Tả Tóm Tắt
Ứng dụng Web hỗ trợ gửi email hàng loạt bằng cách nhập email người gửi, tiêu đề, nội dung và import file Excel danh sách email nhận.

## Cấu Trúc Cơ Bản (Yêu Cầu Từ Anh)
1. **Email người gửi:** Ô nhập email người gửi / cấu hình gửi.
2. **Tiêu đề email:** Ô nhập tiêu đề email (Subject).
3. **Nội dung email:** Khu vực soạn thảo nội dung (Email Body).
4. **Import Excel:** Tải file Excel (.xlsx / .csv) chứa danh sách email khách hàng.

## Tính Năng Gợi Ý Thêm (Nâng Cao)
- Xem trước (Preview) thông tin danh sách email sau khi đọc file Excel.
- Tiến độ gửi mail realtime (Progress bar) & thống kê (Thành công / Thất bại).
- Hỗ trợ chèn biến cá nhân hóa (ví dụ: `{{Tên}}`, `{{Email}}`).
