# Phase 03: Frontend UI & Excel Parser
Status: ✅ Complete
Dependencies: Phase 01

## Objective
Xây dựng giao diện Web phong cách Notion/Linear sang trọng, trực quan với 4 ô chức năng cốt lõi và ô Hẹn Giờ.

## Implementation Steps
1. [x] Component Sender Config: Nhập Email gửi, Mật khẩu ứng dụng (App Password), Service (Gmail/Custom SMTP) & nút `Verify Connection`.
2. [x] Component Email Content Editor: Nhập Tiêu đề (Subject) & Khung soạn thảo nội dung.
3. [x] Component Excel Importer & Data Table Preview: Drag & drop đọc file Excel (`.xlsx`), tự động lọc danh sách email khách hàng kèm ô Tìm kiếm.
4. [x] Component Scheduler & Action Panel: Tùy chọn nút "Gửi Ngay" hoặc "Hẹn Giờ Gửi" (Date & Time Picker) & Màn hình quản lý Lịch hẹn đang đếm ngược.
